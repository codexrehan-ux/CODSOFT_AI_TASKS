# Task 1 — Rule-Based Chatbot

## CodSoft Artificial Intelligence Internship

### Objective

Build a simple chatbot that responds to user inputs using predefined rules and pattern matching. This project demonstrates basic natural language processing concepts and conversation flow.

### Features

- Greets the user
- Identifies common questions
- Provides information about Artificial Intelligence
- Responds to help requests
- Handles unknown inputs gracefully
- Supports `bye`, `exit`, `quit`, and `goodbye` commands

### Technology

- Python 3
- Standard Python library only

### How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python chatbot.py
```

### Example

```text
You: hello
Bot: Hello! How can I help you today?

You: what is AI?
Bot: Artificial Intelligence (AI) is the field of creating systems that can perform tasks that normally require human intelligence.

You: bye
Bot: Goodbye! Have a great day.
```

### Project Requirement

This project is completed as Task 1 of the CodSoft Artificial Intelligence internship.
