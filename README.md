# CODSOFT_AI_TASKS

Artificial Intelligence Internship Tasks – CodSoft

This repository contains my completed projects for the CodSoft Artificial Intelligence internship.

## Completed Tasks

### Task 1 — Rule-Based Chatbot

A simple chatbot that uses predefined rules and pattern matching to respond to user input.

**Technology:** Python

### Task 2 — Tic-Tac-Toe AI

A human-vs-AI Tic-Tac-Toe game using the Minimax algorithm for AI decision-making.

**Technology:** Python

### Task 4 — Movie Recommendation System

A content-based movie recommendation system that compares movie genres and keywords and ranks similar movies.

**Technology:** Python
